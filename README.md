# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/faishal782/fake-news-detection-ai.git
```

## Frontend

```bash
npm install
npm run dev
```

## Backend

```bash
cd backend

python -m venv venv

.\venv\Scripts\activate

pip install -r requirements.txt

uvicorn app:app --reload
```
